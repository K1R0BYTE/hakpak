# hakpak Toolset: every tool hakpak installs, one row per tool.
#
#   section  kind  name  [source...]  # note shown in the README
#
# Sections: top dev network environment basic surfing web pentest cloud cicd mitm wordlists rdp
# Kinds (see install/lib.sh): apt go pipx gem git venv url uv plugin custom
#   uv: `uv tool install`; the source is the package, when its name differs
#   plugin: a Claude Code plugin; the source is its marketplace
#   custom: the source is a function in install/custom.sh
# In a source, $HOME and $HAKPAK_OPT are replaced; nothing else expands.
#
# A tool may be listed in more than one section, with the same kind and
# source in each; within a section, once.
#
# After editing, run tools/gen-readme to update the README tool list.

# --- Top ---
# First, and installable on its own: the shell tools of basic again, plus
# Claude Code. A tool in two sections must have the same row in both.
top  apt     vim
